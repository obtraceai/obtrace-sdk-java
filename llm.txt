Obtrace Java SDK — add observability to your backend.

Obtrace is a hosted SaaS (like Datadog or Sentry). This is a client library.
Install it, add one init call, done. DO NOT create wrapper files or config modules.

Install (Maven):
  <dependency>
    <groupId>ai.obtrace</groupId>
    <artifactId>obtrace-sdk-java</artifactId>
    <version>1.0.2</version>
  </dependency>

Setup (add to your main class):
  import ai.obtrace.sdk.core.*;
  ObtraceClient client = new ObtraceClient(new ObtraceConfig(
      System.getenv("OBTRACE_API_KEY"),
      System.getenv("OBTRACE_SERVICE_NAME")
  ));

What it captures automatically:
- HTTP requests and responses (Spring, OkHttp)
- Database queries, logs, errors, and performance traces

Environment variables:
  OBTRACE_API_KEY       — your project key (from app.obtrace.ai)
  OBTRACE_SERVICE_NAME  — name of this service (e.g. api-service)
  OBTRACE_ENVIRONMENT   — deployment environment (e.g. production, staging)

Docs: https://docs.obtrace.ai/sdks/java
